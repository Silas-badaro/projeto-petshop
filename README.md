# Pet Boutique

Pequeno site institucional para uma Pet Boutique demonstrando serviços, marcas e contato.

## Descrição
Site estático em HTML com estilo em CSS. Contém banner, seção de serviços, marcas parceiras, links para redes sociais e mapa de localização.

## Tecnologias
- HTML5 ([index.html](index.html))
- CSS3 ([style.css](style.css))

## Estrutura do projeto
- [index.html](index.html) — página principal (contém classes como [`.container`](index.html), [`.banner-topo`](index.html), [`.nome-pet-shop`](index.html), [`.titulo-topo`](index.html), [`.rodape`](index.html))
- [style.css](style.css) — estilos do site
- [img/](img/) — imagens usadas pelo site
  - [img/marcas/](img/marcas/)
  - [img/redes-sociais/](img/redes-sociais/)
- [Textos da página/textos.txt](Textos da página/textos.txt) — textos adicionais do projeto

## Como visualizar localmente
1. Abra [index.html](index.html) no navegador.
